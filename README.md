# 戌無极简待办看板

一个简洁的个人待办看板。纯 HTML、CSS 和 JavaScript，无需安装依赖，打开网页即可使用。

## 功能

- 多个看板、自定义状态列，每列独立滚动。
- 拖拽调整卡片顺序和状态。
- 项目与标签管理、筛选和搜索。
- 标准卡片和迷你卡片，暗黑与浅色模式。
- 自定义完成列和完成数量统计。
- 创建时间自动记录，只读显示。
- JSON 备份导入、导出。

## 数据保存

待办内容保存在当前浏览器、当前网址的本地存储中。无需登录，不上传到 GitHub，也不会自动跨设备同步。请定期通过右上角「··· → 导出备份」保存副本。

更换网址或浏览器后，需要从原页面导出备份，再在新页面导入。仓库只包含程序代码，不包含个人待办数据。

## 部署

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支和根目录。无需构建。
