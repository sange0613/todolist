# 戌無极简待办看板

一个简洁的个人待办看板。纯 HTML、CSS 和 JavaScript，无需安装依赖，打开网页即可使用。

## 功能

- 多个看板、自定义状态列，每列独立滚动。
- 拖拽调整卡片顺序和状态。
- 项目与标签管理、筛选和搜索。
- 标准卡片和迷你卡片，暗黑与浅色模式。
- 自定义完成列和完成数量统计。
- 创建时间自动记录，只读显示。
- JSON 备份导入、导出。

## 数据保存

待办内容先保存在当前浏览器。页面底部「数据同步」可输入项目进度页面的同一同步码，自动同步看板、状态分组和事项。通过项目进度右上角「待」打开时，直接使用项目页面的同步连接。

同步使用 Firebase，个人数据不会提交到 GitHub 仓库。同一同步码可用于电脑、手机和 iPad。离线修改先保存在本机，联网后合并；不同事项及同一事项的不同字段分别合并，删除记录也会同步，避免旧设备把已删除事项重新带回来。

原有本机数据会在首次连接时合并。页面处于编辑状态时，云端更新会等保存或关闭编辑后再显示。请保存好同步码，并可继续通过右上角「··· → 导出备份」保存副本。

更换网址或浏览器后，需要从原页面导出备份，再在新页面导入。仓库只包含程序代码，不包含个人待办数据。

## 部署

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支和根目录。无需构建。
